# 육미연합 홈페이지

## 실행 방법

```bash
npm install
npm run dev
```

## 공용 출입 비밀번호

기본 시연용 비밀번호는 `yukmi2026` 입니다.

비밀번호를 바꾸려면 프로젝트 루트에 `.env` 파일을 만들고 아래처럼 설정하세요.

```env
VITE_DEMO_PASSCODE=원하는비밀번호
```

설정 변경 후 개발 서버를 다시 실행하세요.

## 참고

현재 로그인은 프론트엔드 시연용 공용 비밀번호입니다. 실제 비공개 서비스 보안이나 서버 접근 제어를 제공하는 인증 시스템은 아니며, 공개 배포 전에는 서버 측 인증을 별도로 연결해야 합니다.
